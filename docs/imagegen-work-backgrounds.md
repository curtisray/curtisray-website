# Wide project backgrounds

Generated with the built-in imagegen tool on 2026-11-03. Original portrait assets remain unchanged. Each generated image is 1672 × 941px and is copied into the repository; Astro creates optimized delivery variants.

The site renders each texture on a 16:9 canvas behind an expanding mask: 580 CSS pixels high on desktop, and 528–704px on mobile according to viewport height. This zooms the crop out and makes the grain finer while keeping the canvas size unchanged between resting and hover states. Neighbor scale is counteracted on the texture so opening a contracted card does not enlarge its grain.
